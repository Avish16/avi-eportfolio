MediExplain.

Human-centered medical AI that explains complex documents to patients and caregivers — grounded in evidence, never hallucinated.

AGENTS
18+
VECTOR STORE
ChromaDB
RELIABILITY
JSON · Retry · Eval

Streamlit
Challenge

Medical documents are dense, jargon-heavy, and easy to misinterpret. Off-the-shelf LLMs hallucinate facts and lose nuance — dangerous when the reader is a patient or caregiver.

Approach

Outcome

Production-facing Streamlit app with privacy-safe data handling and adaptive response flows for patient vs. caregiver context. Defined evaluation metrics to monitor stability across varied and adversarial inputs.

LV. 03 // COMPUTER VISION · DEEP LEARNING
ARTIFACT 02 / 05

Driver Drowsiness Detection.

Real-time eye-state classification from video, with temporal logic that distinguishes sustained drowsiness from natural blinking.

DATASET
85K+ images
TEST ACCURACY
~98%
ROC–AUC
Near-perfect
DEPLOYMENT
Live + Offline
Challenge

Drowsy driving kills. A reliable detector has to fire on sustained eye closure but not on routine blinks — and it has to run in real time on a webcam stream without false alarms or lag.

Approach

Trained and evaluated multiple architectures on 85K+ labeled eye images. Selected an augmented CNN with the strongest test profile, and built an end-to-end inference pipeline using facial landmarks, left/right probability fusion, and time-based aggregation.

Outcome

Deployed with OpenCV for both live webcam and offline video monitoring. Frame-skipping optimizations and threshold tuning balance reliability, false alarms, and real-time performance.

LV. 03 // TIME-SERIES · NLP
ARTIFACT 04 / 05

Bitcoin Flash Crash Prediction.

A binary classifier for extreme downside Bitcoin minutes — built from minute-level market features fused with Reddit sentiment scored through VADER and FinBERT.

RESOLUTION
Minute-level
SEQUENCE WINDOW
60 minutes
TEST ACCURACY
~71%
TEST SAMPLES
~56.8K
Challenge

Flash crash minutes are rare and devastating. Pure price-action models miss the early signals that often live in social chatter — but raw Reddit text is noisy, sparse per minute, and asymmetric. Detecting them is an imbalanced binary classification problem with real consequences for naive accuracy.

Approach

Engineered minute-level OHLCV features (rolling volatility, drawdowns, momentum, tier flags) and aligned them with per-subreddit VADER sentiment columns plus a parallel FinBERT pipeline. Trained a PyTorch sequence model over 60-minute sliding windows with StandardScaler, validation, and early stopping.

Outcome

Test accuracy ~0.71 at threshold 0.4 on ~56.8K sequenced samples, with class-1 F1 ≈ 0.74 — a credible baseline that fuses two very different signal types into a single risk score, with full classification reports and confusion matrices in the notebook.

PyTorch Python VADER FinBERT Hugging Face Scikit-learn
